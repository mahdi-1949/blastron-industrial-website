# BLASTRON — Industrial Website Demo

قالب نمایشی چندصفحه‌ای برای برند فرضی خدمات سندبلاست، شات‌بلاست و آماده‌سازی سطوح صنعتی.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای انتشار روی GitHub Pages، تمام محتویات این پوشه را در ریشه مخزن قرار دهید و از مسیر Settings → Pages، شاخه اصلی و پوشه `/root` را انتخاب کنید.

## صفحات
- index.html — خانه
- services.html — خدمات
- projects.html — پروژه‌ها
- about.html — درباره ما
- contact.html — تماس با ما

## نکات
- طراحی RTL و واکنش‌گرا
- مگامنوی دسکتاپ و منوی موبایل
- فونت Vazirmatn از Google Fonts
- تصاویر نمونه از Unsplash
- فرم تماس نمایشی است و برای دریافت واقعی اطلاعات باید به بک‌اند یا سرویس فرم متصل شود.
- نام برند، اطلاعات تماس، آمار و پروژه‌ها نمونه هستند و پیش از استفاده تجاری باید با اطلاعات واقعی جایگزین شوند.

## ارتقاهای نسخه دوم
- مگامنوی عریض چهارستونه
- انیمیشن ورود بخش‌ها و نوار پیشرفت اسکرول (با پشتیبانی از کاهش حرکت)
- صفحات مستقل سندبلاست، شات‌بلاست و بلاست سیار
- نمایش تعاملی مفهومی قبل/بعد؛ تصاویر واقعی یک پروژه نیستند


## نسخه سوم
- بازطراحی تایپوگرافی، هدر سینمایی و خدمات تصویری نامتقارن
- مگامنوی تمام‌عرض در کانتینر و منوی اختصاصی موبایل با دکمه سمت راست
- دکمه استعلام قیمت موبایل، فوتر بهینه و جلوه‌های ورود سازگار با کاهش حرکت
- تصاویر آرشیوی آنلاین از Unsplash؛ لازم است قبل از استفاده تجاری ارتباط موضوعی، مجوز و بارگذاری هر عکس بررسی شود
- برند، پروژه‌ها و اطلاعات تماس نمونه‌اند؛ فرم تماس نمایشی است
